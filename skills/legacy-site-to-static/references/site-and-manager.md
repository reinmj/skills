# 静态站、本地管理与多语言

需要本地后台、长期改商品/图片、多语言或自动发布时阅读。一次性静态快照不必增加整套管理系统；沿用合适的生成器或工具也可以。

## 可重建的资料结构

区分三类文件：

1. **原始备份**：源码、完整 SQL、原网页备份，留在私有工作区。
2. **完整编辑资料**：结构化内容、原始 ID、草稿、译稿历史、确认状态、来源摘要及配套图片，可恢复下一次编辑。
3. **公开版本**：HTML/CSS/浏览器 JS、所需图片和明确公开的 JSON/下载材料。只对这一目录执行发布检查与上传。

建议记录项目版本与 schema 版本，给产品、栏目、语言记录稳定 ID。保存来源表/字段/旧 ID 与资源映射。生成公开 JSON 时使用字段白名单；不要先复制完整项目再靠删除几个密码字段清理。

完整编辑资料每次准备发布时保存一份，和不可变发布目录绑定。公开 `site.json` 不是完整备份：私有英文、历史版本和未公开条目本应被过滤。编辑工具版本、内容版本、远程目录名分别显示。

## 避免“新版本上传成功，译文却没了”

- 启动或换资料源时展示：资料版本、产品/文章数量、已确认译文数量。导入更早数据前比较这些值。
- `file://`、不同本地端口、不同浏览器有不同的草稿存储；不能只依赖 localStorage。提供显式完整资料导入/导出。
- 继续编辑优先恢复当前稿或最近一次完整发布资料，不加载初始试用包覆盖它。
- 若已确认译文减少而对应中文没变，先比对旧完整备份并生成恢复资料，不直接丢掉已有成果。恢复和自动公开是不同动作；当前用户意图不明确时说明差异再决定发布。
- 版本号变更、收录设置和文字编辑都使旧发布预览失效；上传前重新生成并校验内容摘要，避免上传旧稿。

## HTML、图片和链接

按恢复后的内容生成模板。迁移正文需要清理危险标签、事件属性和危险 URL，而不是保留旧编辑器插入的任意 HTML。富文本中保留合法段落、表格、列表和图片关系；不要对整段 HTML 直接做文本翻译。

图片优化根据原图和带宽预算选择尺寸、格式与质量；保留原图私有副本。优化后核对图片可解码、比例与清晰度，不简单改后缀。附件只复制已核对的公开材料，不能整目录复制 Uploads、日志或备份。

本地引用检查包括嵌套语言目录、URL 编码、大小写、锚点、CSS 的相对 URL 和图片。无扩展名路由要声明实际路由规则，不能靠默认文件检查猜测。为需要实时后端的表单注明接收端，不用弹窗模拟成功。

## 多语言状态

每条内容、每种目标语言至少区分 missing、draft、reviewed、stale。译文保存其中文/源语言摘要，只有已确认且源摘要一致的版本可以公开。源摘要覆盖实际翻译字段及相关型号/参数，不把“有英文字符串”当作确认。

生成译稿前保存现有内容；超时、服务失败、未完整返回或校验失败时保留旧稿。后台数据导出包含历史和草稿，公开数据只包含当前允许发布的译文。待翻译提示页可以保留 `noindex`，正式收录检查不应强迫它们去掉。

接入翻译服务时核对服务商当前官方额度、认证、QPS 和超额策略。用户选免费服务时不自动切付费产品；把额度、限速和计量实现为项目配置。密钥本地填写并只用于明确的服务，日志中不保存请求密钥或完整私密原文。

型号、数字、负号、区间、单位、大小写及重复出现次数需校验。不要依赖翻译商会原样保留人工构造的保护标记。可优先翻译正常文本，校验后对被改动的型号使用本地分段保护；将受保护的原字面值留在本地，只翻译间隙文本，再合并结果。人工确认仍不可被这些检查替代。图片里印刷的文字另行处理。

## 本地服务

有 FTP 或翻译功能时，提供适合操作者系统的启动入口（Windows 命令脚本、macOS 启动脚本或已安装的 CLI）。界面显示实际本地 URL、运行状态和关闭后清除凭据的行为。只打开 HTML 能编辑不代表有上传服务。

绑定 loopback；校验 Host、Origin 和会话令牌，限制请求大小。只提供明确的静态文件白名单，私有程序、配置、密钥、完整资料与 `local-state` 不可从 HTTP 下载。重启或清除配置会使连接和待发布版本失效；提示用户先保存当前稿，不为修复静态界面自动重启正在上传的进程。

## 发布界面状态

| 状态 | 操作和提示 |
| --- | --- |
| 本地服务未运行 / 页面来源错误 | 提供正确启动方式与本地地址 |
| FTP 未保存或未测试 | 指向“保存并测试连接” |
| 连接通过，无发布预览 | 启用“生成发布预览”，解释上传按钮尚未启用 |
| 已生成当前预览 | 显示内容版本、物理目标、是否正式目录、语言数量，允许上传 |
| 正在处理 | 显示阶段、进度、当前文件；只有真实任务显示等待光标 |
| 已完成 | 显示成功与数量；下次修改后重新生成预览 |
| 失败 / 需要恢复 | 显示失败原因和恢复状态，不伪装成成功或无限加载 |

上传绑定不可变发布 ID 和源摘要。状态轮询来自本地服务，不由光标、按钮颜色或“文件夹存在”推断成功。成功报告区分本次回读验证的文件与依赖缓存跳过的文件。
